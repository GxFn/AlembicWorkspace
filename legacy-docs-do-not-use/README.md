- Active control documents: `codex-control-workspace/.workspace-active/workspace/`
- Active current plan/status/TODO/Test exchange: `codex-control-workspace/.workspace-active/workspace/current/`
- Long-term project ledger and archives: `workspace-ledger/`
- Generic reusable control scripts/templates/skills: `codex-control-workspace/`

If an old file here is still useful, migrate the needed content into `workspace-ledger/` or the active control surface first, then reference the new location.
