# Workspace Task Package Template

状态：长期模板
维护窗口：AlembicWorkspace

本模板用于 `docs/workspace/` 中的 wave 执行计划或验收后的下一波计划。任务包不是把 TODO 简单堆在一起，而是把当前真实阻塞点之前，同阶段、同窗口、同边界、同验证链路下可以安全推进的主线动作和可关闭 TODO 合并成一组可验收任务。

## 反模式

- 不要为了“显得充分”把职责边界不同、验证路径不同或上游未解开的 TODO 塞进同一包。
- 不要遇到未来阻塞就只派阻塞前的最小一小步；先确认阻塞点之前还能做什么。
- 不要把分析发现留在聊天里；未当轮解决的问题必须入 TODO 或说明不入账理由。
- 不要把任务包写成一张大杂烩；每个包都必须有统一完成定义和统一验证路径。
- 不要省略 `AGENTS.md` 读取和窗口定位声明；这两项是派发硬规则，不是建议。
