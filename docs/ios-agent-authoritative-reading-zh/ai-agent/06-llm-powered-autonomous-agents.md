# LLM 驱动的自主 Agent：规划、记忆与工具

- **Original title**：LLM Powered Autonomous Agents
- **原文链接**：[Lilian Weng 原文](https://lilianweng.github.io/posts/2023-06-23-agent/)
- **作者/机构**：Lilian Weng
- **年份**：2023
- **材料类型**：研究综述 / 技术长文
- **文档性质**：忠实中文精读，不是原文全文翻译。

## 文章要解决的问题

在 AutoGPT、BabyAGI 等原型集中出现的阶段，文章试图回答：一个以 LLM 为核心控制器的自主 Agent 通常由哪些部分组成，各部分有哪些研究来源，又有哪些尚未解决的失败点。

## 原文论证主线

全文用三块组织材料。第一是规划：通过任务分解形成子目标，并用自我反思或外部反馈修订计划；第二是记忆：上下文承担短期工作记忆，外部存储与检索承担长期信息访问；第三是工具：补充模型权重中缺失的实时、私有或可执行能力。随后用科学发现 Agent、生成式角色模拟等案例说明组合方式，最后讨论上下文容量、长期规划、自然语言接口可靠性等挑战。

## 关键机制与结论

任务分解可以来自思维链、树搜索、任务专用提示或人类输入；反思把失败轨迹转化为下一轮的条件。长期记忆通常不是把全部历史塞回提示，而是为记录建立表示、索引并按相关性检索。工具把模型从文本生成器扩展为能查询、计算和行动的控制器。文章的隐含结论是，所谓自主性来自这些组件形成的反馈循环，而非 LLM 单独“拥有”稳定目标或永久记忆。

## 证据与适用边界

这是高质量文献地图，不是统一实验。它引用 CoT、Tree of Thoughts、Reflexion、MRKL、Toolformer、Generative Agents 等当时工作，并归纳早期概念验证。文中不少系统基于 2022—2023 年模型，解析格式、规划能力和上下文长度都已变化；向量相似检索也只是长期记忆的一种早期实现，不能直接解决真实性、冲突、更新和权限问题。

## 在知识体系中的位置

它适合作为术语与研究脉络入口：先建立“规划—记忆—工具”三分法，再用 CoALA 获得更严格的架构，用后续上下文、生产和评测材料修正早期原型偏乐观的部分。

## 精读时应保留的判断

这篇文章最适合用来找原始研究，不适合把组件列表直接当实施清单。规划、记忆和工具彼此耦合：错误记忆会误导计划，含噪工具结果会被写入记忆，错误计划又可能调用高风险工具。因此设计评测时要既测单组件，也测端到端传播，并保留来源与轨迹。所谓“反思”只有在它能引用真实失败证据、改变下一动作且经过结果验证时才有意义，重复生成自我评价不等于学习。
