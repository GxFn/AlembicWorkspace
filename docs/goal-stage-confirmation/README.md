# 需求目标与分阶段确认

状态：长期流程目录
维护窗口：AlembicWorkspace

本目录保存“需求目标 + 分阶段确认”的长期流程。它位于需求设计之后、具体 wave 派发之前，用来避免把需求设计文档和执行计划混在一起；可复用模板集中保存在 `templates/`。

## 文档

- [process.md](process.md)：总控收到较大需求后的确认流程。
- [../../templates/goal-stage-confirmation-template.md](../../templates/goal-stage-confirmation-template.md)：任务级最终目标与分阶段确认模板。

## 边界

- 需求原始计划书和需求设计文档放在 `docs/requirement-designs/<需求名>/`。
- 具体总控入口、当前状态、wave 分派、验收和归档仍放在 `docs/workspace/`。
- 本目录只保存长期流程，不保存单次需求的执行派发文档；通用模板统一放在 `templates/`。
