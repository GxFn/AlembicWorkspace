# AlembicWorkspace

This parent workspace is the Codex total-control entrypoint for the Alembic
workspace family.

- Use `codex-control-workspace/` for the generic scripts, templates, skills, and
  source control-workspace rules.
- Use `codex-control-workspace/.workspace-active/` for active control documents.
- Use `workspace-ledger/` for project-specific long-term records.
- `legacy-docs-do-not-use/` contains old documents for historical lookup only.
